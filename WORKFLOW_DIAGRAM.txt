┌─────────────────────────────────────────────────────────────────────────────┐
│                          API ENDPOINTS                                       │
└─────────────────────────────────────────────────────────────────────────────┘

    POST   /api/auth/register
    ├─> Creates driver with driverStatus='pending'
    └─> Returns: User object + JWT token

    POST   /api/auth/login
    ├─> Checks driverStatus before allowing login
    └─> Returns: User object + JWT token (if approved)

    GET    /api/drivers
    ├─> Fetches all drivers from database
    └─> Returns: Array of driver objects

    PUT    /api/drivers/approve/:id
    ├─> Updates driverStatus to 'approved'
    └─> Returns: Updated driver object

    PUT    /api/drivers/reject/:id
    ├─> Updates driverStatus to 'rejected'
    └─> Returns: Updated driver object
